# Estudio · Subalterno Ayuntamiento de Gandia

App de estudio para la oposición de Personal Subalterno del Ayuntamiento de Gandia (3 plazas, BOP de Valencia nº 121 de 29/06/2026).

- Leyes del temario con el texto vigente del BOE, colores de estudio y artículos modificados marcados con 🆕.
- Apuntes de los temas prácticos, ranking de artículos con notas para memorizar y calendario de estudio.
- Preguntas de exámenes reales, simulacro con explicaciones, examen tipo Gandia (40 preguntas, 57 minutos, −1/4) y supuestos prácticos.

El progreso se guarda en el navegador de cada persona. Usa ⬇ Exportar y ⬆ Importar para llevarlo a otro ordenador.
